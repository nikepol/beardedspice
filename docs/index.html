Beardie
Source Releases

Your media keys, pointed at whatever is playing.

Beardie sits in the menu bar and sends play, next and previous to the tab or app actually making sound — not to Apple Music.

♪Paused — SoundCloud, Safari
Download for macOS 2.3.0 · 3.5 MB · macOS 12 or later

What it controls

In the browser

YouTube, Spotify, SoundCloud, Bandcamp, Deezer, Mixcloud, Netflix, Twitch, Apple Music Web, Pandora, Last.fm, Overcast, Pocket Casts, Coursera, and 72 more.

Safari, Chrome and Vivaldi.

As native apps

Music, Spotify, VLC, VOX, Downcast, TIDAL.

Driven through Apple Events, so Beardie asks the app what is playing rather than faking keystrokes at it.

Each site is a small JavaScript file describing how to press play on it. Beardie fetches new and corrected ones from the upstream project, so a site can start working without a new version of the app.

Picking the right tab

With several tabs open, Beardie controls the one currently playing. If nothing is playing it falls back to the focused tab, and failing that, the first supported tab it knows about. You can also pin a tab deliberately with ⌘F8, and jump back to whatever is playing with ⌘F6.

Installing

Requires
macOS 12 or later, Apple silicon or Intel
Permission
Accessibility access, so the app can see the media keys
Size
3.5 MB

The build is not signed. There is no Apple Developer certificate behind it, so the first launch is blocked. Right-click the app and choose Open to get the prompt that lets you through. Every later launch is normal.

Beardie is a fork of BeardedSpice, updated for current macOS. Media strategies still come from the upstream project.
